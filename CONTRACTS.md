# Integration contracts

Lead owns include/lunaviewer/types.hpp, CMakeLists.txt, app/, tests/session*, and main/integration. Workers request shared contract changes through lead. C++17 build; simple C++14-style code. No QObject types in core protocol/session/renderer.

Transport worker owns include/lunaviewer/protocol.hpp, include/lunaviewer/transport.hpp, src/protocol/, src/transport/, tests/transport*. Publish concrete API early. Pure framing/multipart/envelope/crypto/registration/lookup/login/input builders and reply parsing; no implicit live network checks. Qt adapter uses OpenSSL nonblocking TLS, ready/error/frame callbacks and send/close, independently configured address/SNI/verification/Host. Errors may use std::runtime_error in pure functions, caught at executor boundary. Local resource limits mandatory.

Screen worker owns include/lunaviewer/screen.hpp, src/screen/, tests/screen*. Publish concrete API early. Renderer configure(Parts), apply(Parts)->FrameSnapshot, set_tile_size and geometry access; preserve full modern mission ordering and transactional state. Dictionary loaded from explicitly provided local path; no redistribution. Initial frame baseline per source, fixed geometry initially; reject dynamic geometry changes clearly until semantics validated. Bounds before allocation.

UI worker owns include/lunaviewer/ui.hpp, src/ui/, tests/ui*. ControllerWindow Qt Widgets class and callbacks: connect(Credentials), disconnect(), control_enabled(bool), input(InputEvent). Expose display_frame(FrameSnapshot), set_status(string), set_remote_permission(bool). Worker may refine names but publish header early. Input coordinates are remote virtual desktop pixel positions. Frame bgra is top-down packed width*height*4 with explicit stride width*4. UI observes remote permission and explicit local toggle, releases on focus loss/disconnect, and does not own network/session. Ensure snapshot lifetime survives QImage paint. Avoid custom Q_OBJECT when unnecessary.

GUI thread owns window; lead worker bridge runs serialized session+network+decoder. Only completed snapshots coalesced; every delta processed in order. Session generation rejects stale callbacks. ACK18 follows successful decode/commit. Share public headers before implementation settles; do not edit another owner's files. Lead adds all targets/tests to root CMake after reviewing module build requirements. No Windows service contacts during offline tests. Read own progress file at work-batch boundaries, preserve/ack USER messages.
